# Template Assets

Current contents:

- generic cover without institutional or personal branding;
- ten blank content pages with a reusable title area and footer;
- minimal Q&A page.

Before publishing or redistributing this skill, confirm that you have the right to distribute the template's remaining visual assets. Replace any third-party background or decorative image if necessary.
